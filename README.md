# 🎮 Isjianne Dumlao — Game-Inspired PHP Portfolio

An interactive, game-style portfolio built using **PHP, HTML, CSS, and JavaScript**.

This portfolio transforms a traditional personal website into an immersive digital experience complete with XP levels, mission-based navigation, animated backgrounds, and interactive UI elements.

---

## ✨ Features

- 🎮 Game-like interface with Mission Selection
- 🧠 Level and XP Progress System
- 🌌 Animated neon cyber-style background
- 🕹️ Interactive cards with hover effects
- ⌨️ Keyboard-triggered effects
- 📱 Fully responsive layout
- ⚡ Single-file PHP structure for easy deployment

---

## 🛠 Tech Stack

- **PHP** for dynamic content rendering  
- **HTML5** for structure  
- **CSS3** for animations, neon effects, and layout  
- **JavaScript (Vanilla)** for interactions and dynamic content

## 🚀 How to Run Locally

1. Install a local server environment such as XAMPP, MAMP, or Laragon.
2. Place the project folder inside:
   ```
   htdocs (XAMPP)
   ```
   or
   ```
   www (MAMP)
   ```
3. Start Apache.
4. Open in your browser:
   ```
   http://localhost/portfolio
   ```

## 🎯 Core Concept

Instead of traditional navigation like About, Projects, and Contact, the portfolio uses:

- Mission Selection System  
- Level Indicator  
- XP Progress Bar  
- Interactive content rendering via JavaScript  

This design approach gamifies personal branding while maintaining professionalism.

---

## 🧩 Customization Guide

To update personal details, edit the PHP variables at the top of `index.php`:

```php
$name = "Isjianne Dumlao";
$title = "UI/UX Designer & Experience Architect";
$xp = 87;
$level = 12;
```

You may also:

- Adjust neon colors in the `:root` CSS variables
- Modify missions inside the `openMission()` function
- Add real project links inside the Projects section
- Connect the Contact section to a real PHP mail handler
